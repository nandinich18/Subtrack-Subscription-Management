# 💳 SubTrack – Subscription Management Dashboard

**Track Your Subscriptions. Manage Your Spending. Never Miss a Renewal.**

SubTrack is a web-based subscription management dashboard that helps users organize their recurring subscriptions in one place. It allows users to track subscription details, monitor spending, manage renewal dates, and view important subscription statistics through a clean and user-friendly interface.

## 🚀 Features

* 📊 **Dashboard Overview** – View subscription statistics and spending summaries.
* ➕ **Add Subscriptions** – Store service names, plans, amounts, billing cycles, and dates.
* ✏️ **Update Subscriptions** – Edit existing subscription information.
* 🗑️ **Delete Subscriptions** – Remove subscriptions that are no longer needed.
* 🔔 **Renewal Tracking** – Keep track of upcoming subscription renewals.
* 💰 **Expense Monitoring** – Monitor recurring payments and estimated monthly spending.
* 🔍 **Search and Filter** – Find subscriptions and filter records easily.
* 🔐 **User Authentication** – Sign in through the application's authentication interface.
* 📱 **Responsive UI** – Access the dashboard through a modern, user-friendly interface.

## 🎯 Project Objective

The main objective of SubTrack is to make subscription management simple and efficient. It helps users understand their recurring expenses, organize subscription information, and stay aware of upcoming renewals.

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Hatchable hosted backend services
* **Database:** PostgreSQL
* **Authentication:** Hosted authentication services
* **Deployment:** Hatchable

## 📖 How to Use

1. Open the SubTrack website.
2. Sign in using the available authentication option.
3. View the dashboard to check subscription statistics and spending.
4. Add a subscription with its service name, plan, amount, billing cycle, and relevant dates.
5. View, search, filter, update, or delete subscription records.
6. Check upcoming renewal dates to stay organized.
